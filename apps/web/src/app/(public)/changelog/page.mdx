# Changelog

A short, dated record of changes to FresherFlow. Newest first. This page begins today; older changes are not backfilled.

## 25 November 2026

### MCP server for AI clients

FresherFlow now has an MCP server that AI clients such as ChatGPT can connect to. Public job search needs no account. Signing in with a FresherFlow account adds tools for your profile, saved jobs, applications and submissions; moderator accounts can also publish and edit listings.

The limits are deliberate:

- A submission from a normal account is a draft. It is live only when a moderator publishes it.
- The connector cannot apply to jobs or accept offers — applications happen on the employer's site.
- A connection reads only its own account's data.
