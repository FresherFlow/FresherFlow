# FresherFlow

FresherFlow is a job and walk-in opportunity platform for freshers in India. It ingests postings from external sources, normalizes them into one listing contract, serves them through a public feed, and lets candidates search, save and apply — from the web, the mobile app, or an AI client over MCP.

If you want to connect an AI assistant, start with the [MCP guide](/docs/mcp). If you are building against the backend, start with the [API reference](/docs/api).

## What the platform does

- **Collects** postings through the job-discovery and job-processor scripts.
- **Normalizes** them into a single listing shape (`opportunitySchema`) shared by the admin form, ingestion and MCP.
- **Publishes** through a versioned feed on Cloudflare R2, served over the CDN.
- **Serves** public job and company pages, personalized dashboards, and mobile apps.
- **Exposes** the same data as MCP tools, with role-filtered tool lists.

## How a posting reaches a candidate

1. **Discover** — scripts find postings on external sources and record them as raw jobs.
2. **Parse** — `packages/parser` extracts structured fields from the raw text.
3. **Validate** — the API's closed `opportunitySchema` is the one listing contract. Unknown keys are dropped, so field names must be exact.
4. **Review** — community submissions become drafts; moderators approve or fix and publish.
5. **Publish** — the publish flow regenerates the feed from the admin/publish path, never from a public request.
6. **Serve** — a versioned feed object is uploaded to R2 and the CDN serves it to web, mobile and the MCP public tools.

Frontend apps never import Prisma or the database package. They go through `packages/api-client`. Backend business rules live in API application and infrastructure services, with pure helpers in `packages/utils` and `packages/types`.

## Local development

```bash
pnpm install --frozen-lockfile
pnpm db:generate
pnpm turbo lint --filter=fresherflow-api --filter=fresherflow-web
pnpm turbo typecheck --filter=fresherflow-api --filter=fresherflow-web
pnpm turbo build --filter=fresherflow-api --filter=fresherflow-web
pnpm --filter fresherflow-api test
```

`postinstall` deliberately skips Prisma generation. After any change to `schema.prisma`, run `pnpm db:generate` yourself or typecheck will fail on stale types.
