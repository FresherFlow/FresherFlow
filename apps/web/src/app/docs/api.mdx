# API Documentation

FresherFlow provides a comprehensive REST API for managing job opportunities, users, and platform operations.

## Base URL

```
https://api.fresherflow.in/api
```

## Authentication

Most endpoints require authentication via bearer token in the `Authorization` header:

```
Authorization: Bearer <jwt_token>
```

Some public endpoints are available without auth (marked as `PUBLIC`).

## API Versions

The API is versioned. Current version: `v1`.

## Request Validation

All POST/PUT endpoints use Zod schemas for input validation. The primary schema is:

```typescript
// apps/api/src/utils/validation.ts
export const opportunitySchema = z.object({
  title: z.string().min(1),
  company: z.string().min(1),
  location: z.string().optional(),
  // ... more fields
});
```

> **Note**: `opportunitySchema` is a **closed** `z.object`. Unknown keys are stripped, not rejected, so a misspelled field disappears silently.

## Response Formats

### Success Response

```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "count": 10,
    "page": 1,
    "pageSize": 10
  }
}
```

### Error Response

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Validation failed",
    "details": []
  }
}
```

## Rate Limiting

All public API routes (GET and POST) have `express-rate-limit` middleware to prevent abuse.

## Error Codes

| Code | Meaning |
|------|---------|
| `VALIDATION_ERROR` | Input validation failed |
| `AUTHENTICATION_ERROR` | Invalid or missing token |
| `AUTHORIZATION_ERROR` | Insufficient permissions |
| `NOT_FOUND` | Resource not found |
| `RATE_LIMIT_EXCEEDED` | Too many requests |
| `INTERNAL_ERROR` | Unexpected server error |
