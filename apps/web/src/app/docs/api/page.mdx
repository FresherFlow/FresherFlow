# API Reference

The FresherFlow API is the backend for the web app, the mobile apps and the MCP server. The route files under `apps/api/src/routes/` are authoritative for the exact methods and payloads.

## Base URL

```txt
https://api.fresherflow.in/api
```

There is no `/v1` path prefix. OAuth endpoints live at the origin root, for example `https://api.fresherflow.in/oauth/token`.

## Authentication

Most account routes require a bearer token:

```txt
Authorization: Bearer <access_token>
```

Sign in with `POST /api/auth/login` to obtain one. Public routes are marked `PUBLIC` below and need no token. Admin routes require an admin session and the relevant permission.

## MCP

MCP tools are not REST endpoints. They are invoked over the MCP protocol at `https://mcp.fresherflow.in/mcp` with an OAuth 2.1 bearer token issued by this API. See the [MCP guide](/docs/mcp).

The internal surface at `/api/internal/mcp/*` accepts either a user's MCP bearer token or the service key. It is not part of the public API.

## Request validation

POST and PUT bodies are validated with Zod before a handler runs. The central listing schema is `opportunitySchema`:

```typescript
// apps/api/src/utils/validation.ts
export const opportunitySchema = z.object({
  title: z.string().min(1),
  company: z.string().min(1),
  // ... more fields
});
```

> `opportunitySchema` is a **closed** `z.object`. Unknown keys are stripped, not rejected, so a misspelled field disappears silently. Use the exact field names from the route or tool documentation.

A `Json` column such as `applicationDetails` must be set to `Prisma.DbNull`, not bare `null`, when you want a SQL NULL.

## Error format

Errors use one envelope across the API:

```json
{
  "error": {
    "message": "Validation failed",
    "details": [{ "field": "title", "message": "Required" }],
    "requestId": "req_01J..."
  }
}
```

## Rate limiting

Public routes, auth routes, admin mutations and the MCP surface all have rate limits. MCP and OAuth paths use dedicated per-user or per-route limiters rather than the global per-IP bucket; see the [MCP rate limits](/docs/mcp#rate-limits). A 429 response includes `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset` headers.
