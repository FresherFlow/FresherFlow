# MCP Server

Connect an AI client to FresherFlow. Search live jobs, save listings, submit opportunities and — with moderator permissions — review the queue. The server is a thin Cloudflare Worker over the FresherFlow API: no database connection, no service key, and every account action uses your own OAuth token.

## Endpoint

<DocEndpoint value="https://mcp.fresherflow.in/mcp" />

Public, read-only discovery works without an account:

<DocEndpoint value="https://mcp.fresherflow.in/mcp/public" />

<DocCallout variant="note" title="Public endpoint">
  `/mcp/public` exposes only `get_jobs`, `get_job` and `get_company_jobs`. It never returns account data.
</DocCallout>

## Connect a client

Add FresherFlow as an HTTP MCP server in your client.

### Claude Code

```bash
claude mcp add --transport http --scope user fresherflow https://mcp.fresherflow.in/mcp
```

### Cursor

Add `https://mcp.fresherflow.in/mcp` as a remote MCP server in Settings → MCP, then sign in when prompted.

### ChatGPT and Codex

Use the **Add connector** or **Add MCP server** flow in your client settings and paste the endpoint above. Sign in with your FresherFlow account to finish.

The first connection takes you through OAuth. After you approve access, the client can call tools with your own permissions.

## What you can do

Ask in plain English — the client picks the tool.

- **Find work.** "Find fresher jobs in Hyderabad" or "Show me remote internships that need React."
- **Check a match.** "I graduate in 2027 with a B.Tech in CSE — what fits me?" Your profile supplies the filters, and each result is checked against its eligibility fields.
- **Track applications.** "Where did I apply, and what stage am I at?"
- **Save jobs.** "Save this job for later."
- **Submit an opportunity.** "Add this job to FresherFlow" — a draft for a normal account, published immediately for a moderator.

## Tools

The tool list a connection sees already reflects its role. A normal account never sees moderation tools.

### Discovery

Available to everyone.

`get_jobs` — Search by keyword, city, company, type, degree, skill, work mode, age or deadline.

`get_job` — Full detail for one listing by slug or id.

`get_company_jobs` — Whether one company has live jobs, its listings and company page.

### Your account

Sign-in required.

`whoami` — Connection identity, role and capabilities.

`get_my_profile` — Your education, pass-out year, skills and preferred cities or work modes.

`list_saved_jobs` — Bookmarked jobs with deadlines and apply links.

`save_job` — Bookmark or unbookmark one listing.

`list_my_applications` — Application records and their stages.

`submit_opportunity` — Submit a job. A draft for users, published for moderators.

`list_my_submissions` — Your submissions and their status.

`withdraw_submission` — Withdraw a submission waiting for review.

### Moderation

Review and publish permissions required.

`get_listing` — Read a full existing listing.

`update_listing` — Fully replace an existing listing.

`review_queue` — Submissions awaiting review.

`approve_submission` — Publish a submission.

`reject_submission` — Reject a submission with a reason.

<DocCallout variant="note" title="Write tools carry their own contract">
  Each write tool describes its own fields. There is no separate schema or template tool.
</DocCallout>

## Agent skills

Tools expose capability; [skills](/docs/skills) carry the sequence and the rules.

- **submit-opportunity** — go from a link or pasted posting to one complete submission.
- **job-search** — search the live feed with accurate filters and return canonical links.
- **review-submissions** — one decision per submission: approve, reject with a reason, or fix and publish.
- **fresherflow-coach** — turn a profile into a focused search and application plan.

## Authentication

The MCP server is an OAuth 2.1 resource server. The FresherFlow API is the authorization server.

1. The client fetches protected-resource metadata.
2. It registers through dynamic client registration.
3. It redirects you to the FresherFlow consent screen.
4. After approval, it exchanges the code for tokens.
5. Every tool call sends `Authorization: Bearer <access_token>`.

PKCE S256 and the RFC 8707 `resource` parameter are required. Access tokens last 24 hours; refresh tokens rotate.

<DocCallout variant="tip" title="Tool list changed after a permission grant?">
  Clients cache the tool list. Use **Refresh tools** in your client or reconnect. `whoami` can show `moderator` while the visible tools are still the old set.
</DocCallout>

Manage or revoke connections under **Settings → Connected apps** in the web app.

## Rate limits

The MCP worker allows 600 requests per minute per client IP. Per-account limits apply to `submit_opportunity` (60/hour), listing writes (60/minute), listing reads (120/minute) and moderation actions (30/minute). A 429 response includes `Retry-After` and the original request id so the client can retry just that call.

## Troubleshooting

- **401 on the first call** — expected. The client follows the resource metadata URL and completes OAuth.
- **Tools missing** — check `whoami`. A normal account cannot see moderator tools.
- **Connection keeps asking to reconnect** — refresh tools, then check **Settings → Connected apps**.
- **429** — wait for `Retry-After` and retry. Do not reconnect.
